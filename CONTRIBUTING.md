# Contributing to Self Host Form

Thanks for your interest in improving Self Host Form! Everyone is welcome to contribute.

## Ways to help

- Report bugs or suggest features in [Issues](https://github.com/Dev-Xrab/self-host-form-app/issues)
- Ask questions or share ideas in [Discussions](https://github.com/Dev-Xrab/self-host-form-app/discussions)
- Improve the documentation
- Fix a bug or build a feature. Look for issues labeled `good first issue` or `help wanted`.

## Development setup

1. Fork the repo and clone your fork.
2. Install Node.js 22.5 or newer.
3. Run `npm install`.
4. Run `npm run server` and `npm run dev`, or `npm run desktop` for the Electron app.

## Making a change

1. Create a branch from `main`, for example `fix/export-crash` or `feat/rubric-grading`.
2. Keep each change focused. One pull request should cover one topic.
3. Match the style of the surrounding code, and run `npm run lint` before pushing.
4. Test your change in the app, both the host dashboard and the respondent view if it affects them.
5. Write clear commit messages that say what changed and why.
6. Open a pull request and fill in the template. Link the issue it fixes, for example `Fixes #12`.

## Reporting bugs

Please include:

- Your OS and app version
- Steps to reproduce the bug
- What you expected and what happened instead
- Screenshots or logs, if you have them

## Security

Don't report vulnerabilities in public issues. See [SECURITY.md](SECURITY.md).
